# SEO.md
# Vapi Freelance Portfolio — Local SEO Strategy

## 1. SEO Objective

Establish a strong organic search presence for freelance website development and digital services in Vapi, Gujarat.

Primary objective:
Generate qualified local inquiries from businesses searching for website design, web development and related digital services.

The website is a single-page portfolio. SEO must work within that architecture without creating unnecessary pages.

## 2. Geographic Targeting

Primary location:
Vapi, Gujarat, India.

Secondary geographic coverage:
- Pardi.
- Dungra.
- Sarigam.
- Umbergaon.
- Silvassa.
- Daman.

Only mention nearby locations where services are genuinely available.

Never invent a physical business address or local office.

## 3. Keyword Strategy

### Primary keywords

- website designer in Vapi
- website development in Vapi
- freelance web developer in Vapi
- website design in Vapi Gujarat
- web development services in Vapi

### Secondary keywords

- business website design in Vapi
- industrial website development in Vapi
- website redesign in Vapi
- e-commerce website development in Vapi
- custom web application development in Vapi
- AI chatbot development in Vapi
- website developer near Vapi GIDC

### Industry-related keywords

- manufacturing website design in Vapi
- industrial company website development
- clinic website design in Vapi
- school website development in Vapi
- workshop website design in Vapi
- business website development in Gujarat

Do not repeat keywords unnaturally.

Use variations naturally within headings, descriptions and image context.

## 4. Search Intent

Prioritize:

Commercial intent:
People looking for website development services.

Transactional intent:
People ready to contact a website developer.

Local intent:
Businesses searching for developers in Vapi and nearby areas.

Informational intent:
Business owners learning why they need a website or how to improve an existing one.

Content must prioritize commercial and local search intent.

## 5. Metadata

Create unique metadata using the Next.js Metadata API.

Suggested title:

Website Designer & Freelance Web Developer in Vapi, Gujarat | Samir

Suggested description:

Looking for a website developer in Vapi? I build modern business websites, industrial websites, web applications and AI-powered experiences for growing businesses.

Requirements:
- Unique page title.
- Compelling meta description.
- Canonical URL using the actual production domain.
- Open Graph title and description.
- Open Graph image.
- Twitter/X metadata.
- Favicon and application metadata.

Do not use misleading SEO claims.

## 6. Heading Structure

One primary H1.

Suggested H1:

Modern Websites for Growing Businesses in Vapi.

Supporting H2 themes:

- What I Can Build for Your Business.
- Digital Experiences for Different Industries.
- Selected Projects.
- A Better Digital Presence for Your Business.
- How We Work.
- Let's Build Something Together.

Use descriptive and natural headings.

## 7. Local SEO Content

Naturally communicate:

- Based in Vapi, Gujarat.
- Freelance web development services.
- Industries and business types served.
- Local project relevance.
- Nearby service coverage.
- How businesses can contact the developer.

Include relevant Vapi and GIDC context without repeating location keywords in every section.

Do not create fake local landing pages.

## 8. Structured Data

Implement appropriate JSON-LD structured data.

Potential types:
- Person.
- WebSite.
- ProfessionalService or LocalBusiness, where eligible and accurate.
- Service, where appropriate.

Use truthful information only.

Business information must be consistent across the website and structured data.

Do not invent:
- Street address.
- Telephone number.
- Office hours.
- Aggregate ratings.
- Reviews.
- Geographic coordinates.
- Client count.

Avoid misleading organization markup for an individual freelancer.

## 9. Technical SEO

Implement:

- Next.js Metadata API.
- XML sitemap.
- robots.txt.
- Canonical metadata.
- Semantic HTML.
- Crawlable text content.
- Proper heading hierarchy.
- Descriptive internal links.
- Optimized image delivery.
- Correct image dimensions.
- Descriptive alt attributes.
- Open Graph metadata.
- Structured data.
- HTTPS in production.
- Clean URL and anchor structure.

Ensure important text is available in rendered HTML and is not accessible only through WebGL or animation.

## 10. Image SEO

Use descriptive image filenames.

Examples:
- vapi-industrial-website-design.webp
- business-website-development-vapi.webp
- manufacturing-website-showcase.webp
- vapi-freelance-web-developer-project.webp

Use meaningful alt text.

Avoid keyword stuffing in alt attributes.

Use AVIF or WebP where appropriate.

Use next/image and lazy-load below-the-fold assets.

## 11. Performance SEO

Optimize:
- Largest Contentful Paint.
- Interaction to Next Paint.
- Cumulative Layout Shift.

Priorities:
- Optimize hero image.
- Reserve image dimensions.
- Lazy-load 3D scenes.
- Avoid oversized JavaScript.
- Optimize font loading.
- Minimize layout shifts.
- Avoid unnecessary animation scripts.

Do not allow visual effects to compromise page speed.

## 12. Local Search Visibility

Set up:
- Google Search Console.
- Google Analytics 4 if consent and privacy requirements are addressed.
- Google Business Profile only if eligible under Google's guidelines.
- Appropriate business contact details.
- Consistent personal identity across professional profiles.

Do not create a fake office listing or use a virtual address to misrepresent business location.

## 13. Conversion Tracking

Track meaningful interactions:

- WhatsApp clicks.
- Call clicks.
- Email clicks.
- Inquiry form starts.
- Successful inquiry submissions.
- Project link clicks.

Do not count failed form submissions as conversions.

## 14. SEO Validation

Before launch:

- Validate title and description.
- Verify canonical URL.
- Check robots.txt.
- Check sitemap.
- Test structured data.
- Check mobile rendering.
- Check image alt attributes.
- Test indexability.
- Verify HTTPS.
- Submit sitemap to Search Console.

## 15. SEO Content Principles

SEO must support the user experience.

Never:
- Stuff location keywords.
- Generate fake testimonials.
- Create thin duplicate pages.
- Hide keywords.
- Add irrelevant city names.
- Invent business facts.
- Sacrifice readability for rankings.

The website must be useful to local business owners first and search engines second.
